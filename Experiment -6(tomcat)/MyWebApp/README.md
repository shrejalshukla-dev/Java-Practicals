# Apache Tomcat Experiment

## Aim
To create and run a simple HTML web application using Apache Tomcat.

## Software Requirements
- Java Development Kit (JDK)
- Apache Tomcat 11.0.25
- Visual Studio Code
- Web Browser

## Project Structure
```text
Tomcat-Experiment/
├── MyWebApp/
│   └── index.html
└── README.md
```

## How to Run
1. Download and extract Apache Tomcat.
2. Copy the `MyWebApp` folder into Tomcat's `webapps` directory.
3. Start Tomcat using `bin/startup.bat`.
4. Open `http://localhost:8080/MyWebApp/` in a browser.

## Expected Output
Welcome to My Web Application

This application is running on Apache Tomcat.

## Result
A simple HTML web application was successfully created and executed using Apache Tomcat.
